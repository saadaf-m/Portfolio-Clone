# Portfolio-Clone
The goal of this project is to clone my current portfolio website using tailwindCSS.

# Why?
Why are you building out the same project again? Well, there's two reasons. The primary one is that my first website was built with Desktop-first approach, but I'd like to it mobile-first approach. Second is just because I've grown a liking towards tailwind. Actually, Tailwind is designed to make mobile-first development easy.
